## Wichtig beim Hochladen

Alle Dateien und den Ordner `assets` direkt in das Hauptverzeichnis des
Repositorys `RSVU-Beratung` hochladen. Insbesondere müssen `index.html` und
alle PDF-Dateien auf derselben Ebene liegen.

Die PDFs dürfen nicht umbenannt werden. Die Anwendung erwartet exakt diese
Dateinamen:

- `avb-04-2026-vollstaendig.pdf`
- `avb-b-betriebsalltag.pdf`
- `avb-c-mitarbeitende.pdf`
- `avb-d-kundinnen-lieferanten.pdf`
- `avb-e-fahrzeuge.pdf`
- `avb-f-zusaetzliche-liegenschaften.pdf`
- `avb-g-recht-plus.pdf`

Unter **Settings → Pages** einstellen:

- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/(root)**

Version 19 enthält zusätzlich die Korrektur der Rückwärtsnavigation.
